# Реестр поставщиков

**Компания:** Northwind Coffee Roasters LLC · **Ведёт:** Мария Ковалёва (руководитель финансов) · **Пересмотр:** ежеквартально

В реестре перечислены **официальные контакты для обратного звонка** по нашим постоянным получателям и маскированная сводка их реквизитов.
Актуальные данные — в ScamPause (раздел «Поставщики и получатели»); этот документ — печатная справка для аудита.
Показаны только последние четыре цифры счетов. Полные номера видят в ScamPause уполномоченные сотрудники, и каждый просмотр записывается в журнал.

## Как пользоваться контактами

- Используйте эти номера для «Стоп. Позвони. Подтверди.» — они взяты из договоров, проверенных сайтов или получены лично.
- Никогда не заменяйте номер из реестра номером из счёта или письма. Изменения реестра — только через руководителя финансов и по документу-основанию.

указывается только наличие проверенного счёта (например, Jordan Lee — ACH на **2291**, подтверждён лично в июне 2025).
